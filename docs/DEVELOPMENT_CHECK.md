Проект состоит из статической страницы (`index.html`, `style.css`, `app.js`), сервера на стандартной библиотеке Python и пар скриптов запуска/загрузки ресурсов для Windows и macOS. Сборщик не нужен. Файлы интерфейса и игровой логики оставлены без изменений.

На момент проверки `assets/` отсутствует. Режим мыши не импортирует MediaPipe; управление камерой требует предварительной загрузки ресурсов скриптом SETUP. В обоих скриптах указана одна версия tasks-vision: 0.10.21 и одна модель Hand Landmarker. Загрузка ресурсов по сети в этой проверке не выполнялась.

Добавлены `.gitignore`, `data/.gitkeep`, `AGENTS.md`, проверки API и план расширения. `data/records.json` исключён из индекса Git, но оставлен на диске с исходным содержимым `{"bestScore": 0}`. Игнорирование ресурсов, рекордов и кэша Python проверено через `git check-ignore`.

Исправлены два ответа API:

- JSON, который не является объектом, получает 400 вместо ошибки 500.
- Ошибка чтения хранилища при POST получает 500 вместо ответа 400 об ошибке запроса. Повреждённый файл не перезаписывается.

README дополнен прямыми командами запуска, командами проверок для обеих ОС, описанием API и восстановлением повреждённого файла. Исправлено описание переноса старого рекорда: код проверяет старое значение при каждой загрузке страницы, а не только один раз. Дублирующий `README_RU.md` заменён ссылками на основную инструкцию.

## Выполненные проверки

Среда: macOS, Python 3.14. Использована только стандартная библиотека.

`python3 -m unittest discover -s tests -v` — **7 тестов пройдены**:

1. Сервер отдаёт HTML, CSS и JavaScript без изменения содержимого, с запретом кэширования.
2. При отсутствии папки данных возвращает нулевой рекорд; первая запись создаёт каталог и JSON без оставшегося временного файла.
3. После записи 650 процесс сервера полностью завершается и запускается заново. GET возвращает 650; запись 10 сохраняет 650; запись 700 обновляет максимум.
4. Некорректные JSON, типы и диапазоны счёта получают 400 и не меняют файл.
5. Посторонний Origin получает 403, неизвестный POST-маршрут — 404; оба локальных Origin разрешены.
6. Шесть одновременных записей сохраняют максимальный результат 700.
7. Повреждённый JSON, отрицательный рекорд, boolean и отсутствие bestScore дают 500 при чтении и записи; исходный файл остаётся целым.

Тесты используют отдельные процессы HTTP-сервера, свободные порты и временные папки рекордов. Пользовательские данные не используются.

`bash -n START_MAC.command SETUP_MAC.command`, `node --check app.js` и `git diff --check` — успешно.

## Что осталось проверить на целевом компьютере

Штатный порт `127.0.0.1:8767` занят ранее запущенным процессом Python (PID 15188 на момент проверки). Попытка запустить второй `server.py` дала `Address already in use`; чтение уже работающего сервера завершилось сбросом соединения. Этот процесс не останавливался. Для штатного запуска нужно остановить прежний сервер в его терминале, затем запустить актуальную версию. Работоспособность текущего обработчика подтверждена тестами на свободных портах.

Windows и PowerShell в среде проверки недоступны. Команды `py -3 server.py`, резервный вариант `python server.py`, пути и скрипты Windows проверены по коду, без исполнения. Скрипты macOS проверены синтаксически; запуск браузера через START и загрузка MediaPipe не выполнялись.

Полный раунд в браузере, камера, FPS, полноэкранный режим и автономная работа с загруженной моделью требуют ручной проверки по списку из README. Результаты API-тестов не заменяют эти проверки. Минимальные характеристики оборудования не заявлены без замеров на ноутбуках мероприятия.
