# Расширение нейроаркады

Это план дальнейших изменений. В подготовке версии 2.4 новые игры и общее меню не реализуются.

## 1. Зафиксировать исходную игру

Сохранить текущий внешний вид, 60-секундный раунд, начисление очков, бонусы и оба способа управления «Лови код». Перед переносом кода пройти ручные проверки из README на Windows и macOS. Замерить FPS и отзывчивость камеры на ноутбуках, которые будут использоваться на мероприятиях; конкретный порог выбрать по результатам замеров.

## 2. Добавить выбор игр

Сделать отдельный экран выбора с русскими названиями и короткими правилами. «Лови код» оставить самостоятельной игрой с прежним оформлением. Поначалу новые игры можно разместить в отдельных каталогах `games/`, не разбирая работающий `app.js` на модули заранее.

После появления второй игры выделить только действительно общие части: получение координат руки/мыши, включение и остановку камеры, звук и обращение к API. Загружать модель по запросу и использовать один экземпляр распознавателя. Для игры предусмотреть запуск, остановку и очистку ресурсов. При возврате в меню не должны оставаться лишние циклы анимации, обработчики и активная камера.

## 3. Разделить рекорды

До подключения второй игры добавить идентификаторы игр и отдельный максимум для каждой. Возможный формат: `{"schemaVersion": 2, "games": {"catch-code": {"bestScore": 650}}}`. При миграции переносить существующий `bestScore` только в «Лови код», предварительно сохранив резервную копию. Не сравнивать очки разных игр.

API должен принимать только известные идентификаторы игр. Сохранить атомарную запись, блокировку и проверку чисел. Добавить проверки миграции, повторного запуска и независимости рекордов. До этой задачи формат версии 2.4 не менять.

## 4. Добавлять по одной мини-игре

| Игра | Что делает игрок | Связь с профориентацией |
| --- | --- | --- |
| «Сортировщик данных» | Перемещает карточки в нужную категорию рукой или мышью | Разметка данных и классификация |
| «Поймай сигнал» | Наводит курсор на появляющиеся цели | Обработка сигналов, точность и задержка управления |
| «Собери алгоритм» | Выбирает шаги в правильном порядке | Последовательности, условия и алгоритмы |

Первой сделать «Сортировщик данных»: она использует уже доступные координаты указателя и не требует новой модели. Для первой версии достаточно наведения с удержанием, чтобы не вводить распознавание новых жестов. Для каждой игры сначала описать правила, очки и завершение раунда, затем сделать режим мыши, после него подключить ладонь.

## 5. Проверить комплект для мероприятий

На Windows и macOS пройти запуск, переключение игр, повторные раунды и сохранение рекордов после перезапуска. Проверить отключённую и занятую камеру, отсутствие модели и запрет записи. Отдельно проверить работу без интернета и отсутствие роста нагрузки после нескольких переключений. Распространять папку с уже загруженными ресурсами; для разработки оставить ресурсы вне Git. Новые зависимости добавлять только при подтверждённой необходимости.
